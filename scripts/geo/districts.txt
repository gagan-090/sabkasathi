# Source of truth for district → town assignment.
#
# Format:   State name on a "@" line, then one district per line as
#           District name | town, town, town
# Comments: lines starting with "#" and blank lines are ignored.
#
# This file exists because lib/geo.ts held nine states as one flat, ungrouped
# town list — the towns were real but nobody knew which district they sat in,
# and guessing would have put factual errors on public pages. These groupings
# were supplied by the business owner. scripts/geo/build.mjs merges them into
# lib/geo.ts; edit here and re-run that, never hand-edit lib/geo.ts.
#
# Deduplication is by slug within a state, first district wins. India reuses
# town names heavily (Uttar Pradesh has two Bandas; Chhattisgarh has a Patna),
# so a town can only be filed under one district for URL purposes.
